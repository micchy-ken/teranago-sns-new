# Implementation Plan - スタンプ管理画面およびカスタム画像アップロード機能の実装

ユーザーが管理画面から任意のスタンプ画像（ナノバナナキャラ等）を一括・個別でアップロードおよび差し替えでき、チャット画面で透過処理（背景自動透過またはクロップ処理）されたスタンプとしてリアルタイムに利用できるように拡張します。

---

## 1. 概要・目標

1. **管理画面（AdminPanel）へのスタンプ管理タブ追加**
   - スタンプ画像（全15枠、または新規追加枠）の一覧表示。
   - 個別ドラッグ＆ドロップ / ファイル選択での画像差替。
   - 複数スタンプが含まれたグリッド画像（2x3等）の一括アップロード・6分割自動自動クロップ・透過処理機能。
2. **背景自動透過処理（Canvas 処理）**
   - アップロードされた画像から白地や背景色を検知・自動除去し、透明背景（PNG DataURL / サーバーアップロード）を生成。
   - プレビューと微調整（感度・許容値調整）の提供。
3. **データ保存と同期**
   - `/public/stamps/` または `/uploads/stamps/`（およびデータ永続化ストレージ `data/stamps.json` / MS SQL Server `stamps` テーブル）への保存。
   - 全クライアントへのリアルタイム・即時反映。

---

## 2. 変更対象ファイルと構成

1. **`/src/components/AdminPanel.tsx`**
   - 管理メニューに「スタンプ管理」セクションを追加。
   - スタンプ画像のアップロード、透過パラメータプレビュー、カテゴリ別整理 UI の実装。
2. **`/src/utils/imageUtils.ts` (新規)**
   - HTML5 Canvas を使用した画像自動背景透過処理（カラーキー除去 / ガウス平滑化 / 切り出し）ユーティリティ。
3. **`/src/components/Chat.tsx`**
   - カスタムアップロードされたスタンプ動的データの読み込みとフォールバック処理。
4. **`/server.ts` & `/routes/stamps.js` (新規/拡張)**
   - スタンプ画像アップロード API `/api/stamps/upload` および設定保存 API `/api/stamps` の実装。
5. **`/src/components/RecommendServerCode.ts`**
   - `server.ts` / `routes/stamps.js` のバックエンド推奨コード同期。

---

## 3. 実装手順

### Step 1: バックエンド API & アップロード処理 (`server.ts`, `/routes/stamps.js`)
- `multer` ストレージ設定に `/uploads/stamps/` を追加。
- スタンプの定義（ID、カテゴリ、表示テキスト、画像URL）の永続化管理。

### Step 2: フロントエンド画像透過・分割ユーティリティ (`src/utils/imageUtils.ts`)
- 画像分割ロジック（指定グリッド行・列でトリミング）。
- 背景透過キャンバス処理（白/背景色のアルファ閾値処理）。

### Step 3: 管理画面 UI の構築 (`src/components/AdminPanel.tsx`)
- スタンプ管理タブの設計（グリッド一覧、プレビュー、アップロードダイアログ）。
- 一括画像アップロード＆分割透過プレビューモーダルの設置。

### Step 4: チャット画面との動的連携 (`src/components/Chat.tsx`)
- カスタムスタンプデータの取得とパレット・メッセージタイムラインへの即時描画。
