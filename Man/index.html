寺岡オートドアSNS / 寺子屋SNS 総合操作マニュアル

社内ナレッジの蓄積・タイムライン・日報・チャット・点検予定管理・文書キャビネット・安否確認の全機能を網羅した公式操作ガイドです。

バージョン: v2.6.0 (完全版) 最終改定日: 2026年10月2日 対象: 全社員・管理者・現場技術員
🌟 第1章: はじめに・システム概要・推奨環境
全員対象

本システムは、寺岡オートドアグループの技術・現場ナレッジの共有、スケジュール・点検予定の可視化、災害時の迅速な安否確認を実現する社内統合プラットフォームです。

推奨利用環境・PWAインストール

  • 推奨ブラウザ: Google Chrome, Microsoft Edge, Safari (最新版)
  • スマートフォン / タブレット (PWA対応): ブラウザのメニューから「ホーム画面に追加」または「アプリをインストール」を実行すると、ネイティブアプリのように全画面かつプッシュ通知受信対応で快適にご利用いただけます。
  • バックエンド同期: 社内Synology NAS上のセキュアなMS SQL Serverおよび暗号化ストレージとリアルタイムに同期しています。
🏠 第2章: タイムライン (社内ナレッジSNS)
全員対象

日常の気づき、現場でのトラブルシューティング、社内連絡を気軽に発信・共有できるタイムラインです。

主な機能と操作

機能 説明 操作方法
新規投稿・つぶやき テキスト、画像添付（複数枚・自動リサイズ）、現場写真の投稿。 画面上部の投稿フォームから入力し「投稿」ボタンを押す。
アンケート機能 選択肢形式の社内アンケートを作成・即時集計。 投稿欄の「📊 アンケート作成」アイコンをクリック。
スタンプ・リアクション いいね！、お疲れ様、感謝などのオリジナルスタンプをワンタップ送信。 投稿下のスタンプボタンから選択。
コメント・スレッド返信 投稿に対する詳細な議論や追加情報のスレッド返信。 「返信する」をクリックして入力。
📋 第3章: 業務日報・現場作業報告
全員対象

日々の業務進捗、現場施工・保守点検の作業記録を作成し、上長やメンバーへ共有・フィードバックを受けるタブです。

日報の作成・承認フロー

  1. 「新規日報作成」ボタンをクリックします。
  2. 作業現場・件名・作業内容・特記事項を入力します（テンプレートから自動引用も可能）。
  3. 現場写真を添付し、「提出する」または「下書き保存」をクリックします。
  4. 上長・管理者は提出された日報を確認し、「承認・コメント」を行うことができます。
📢 第4章: 社内掲示板・お知らせ
全員対象

全社通達、総務・経理からの重要連絡、安全衛生情報などをカテゴリ別に閲覧できる公式掲示板です。

掲示板の特徴

  • 重要ピン留め: 最重要通達は一覧の最上部に固定表示されます。
  • 既読・未読トラッキング: 誰が掲示を確認したかを投稿者が確認できます。
  • 添付ファイルプレビュー: PDFや画像ファイルをブラウザ上で直接プレビューできます。
💬 第5章: グループチャット・ダイレクトメッセージ
全員対象

部署別・プロジェクト別のルームチャットおよび個人間のダイレクトメッセージ（DM）が可能です。

💡
メンション機能: @名前 を入力すると、対象者にプッシュ通知・メール通知が送信されます。
📅 第6章: 共有カレンダー・予定管理
全員対象

社員全員の予定、現場工事、定期点検、社内行事を日・週・月単位で可視化します。

カレンダー連携機能 (iCal / Google / Outlook)

  • 外部カレンダー購読: カレンダー右上の「iCal連携」からURLを取得し、GoogleカレンダーやiPhone/Outlookに登録すると、社外からでも自動同期されます。
🗓️ 第7章: 点検予定一括登録・管理
要権限（管理者または個別許可）
🔑
利用権限について: この機能は「管理者」または管理者パネルで「点検予定管理メニューの表示」が許可されたユーザーのみ利用可能です。

毎月の定期点検Excel（26列実フォーマット）を取り込み、日付配置・担当者割り当て・現場カレンダーマトリクスExcel出力を一気通貫で行う専用機能です。

主な機能一覧

機能名 説明
実フォーマットExcel取込 Excelファイル（.xlsx）をドラッグ＆ドロップし、C1セルの年月や26列の現場データを自動読み込み。
現場マスター自動補正 過去の点検実績から「現場ごとの開始時間・貼紙・作業届・WEB入力区分・備考」を自動引き継ぎ。
他月・前月データコピー 他月の下書きや配置済みデータをマスター情報付きでワンクリック一括コピー。
点検予定表Excel出力 【新機能】 現場カレンダー形式（縦軸＝日付・曜日、横軸＝案件、土日色分け・特記事項オレンジ強調）で完全互換のExcelを出力。
カレンダー確定反映 仮配置した点検予定に担当メンバーを割り当て、共有カレンダーへ一括登録。
📁 第8章: 社内文書管理・キャビネット
全員対象（一部フォルダは権限制御）

社内規程、マニュアル、申請書テンプレート、現場図面などを階層フォルダで安全に一元管理します。

特徴と操作ルール

  • 文書タイトル・アイコンをクリック: 文書の詳細モーダルが開き、説明文・更新者・全バージョン改定履歴を確認できます。
  • 添付ファイル名をクリック: ファイル名をクリックするだけで、ブラウザ内で即座にインラインプレビュー（PDF・画像・テキスト）が表示されます。
  • フォルダ公開範囲: 「全員公開」または「特定メンバーのみ閲覧許可」を設定できます（設定は作成者・管理者のみ）。
  • バージョン管理: 改定時は「新バージョン登録」を行うことで、過去の履歴や旧ファイルを残したまま最新版へ更新できます。
  • DL履歴トラッキング: 誰がいつ文書をダウンロード・閲覧したかの監査ログが自動記録されます。
🗄️ 第9章: NAS共有ファイル (社内ストレージ連携)
要権限（個別許可）

社内NAS（Synology）上の特定共有フォルダと直接連携し、外出先やブラウザから安全にファイルを閲覧・ダウンロードできます。

🦺 第10章: 安否確認・緊急BCP連絡
回答:全員 / 発動:要権限

地震・風水害などの緊急事態発生時に、全社員へ一斉に安否確認を発動し、回答状況をリアルタイムで集計するBCP機能です。

安否回答の流れ（全社員）

  1. 安否確認が発動されると、アプリ画面上部に「緊急安否確認バナー」が表示され、Webプッシュ通知およびメールが送信されます。
  2. バナーの「安否を回答する」をクリックします。
  3. 「本人無事 / 軽傷 / 重傷」「出社可否」「家族の状況」「現在地（位置情報）」を選択して送信します。
⚠️
安否確認の発動権限: 誤発動を防ぐため、安否確認の一斉発動は「管理者」または「安否確認発動権限」を持つ担当者のみ実行できます。
👥 第11章: 社員名簿・プロフィール
全員対象

所属部署、役職、内線番号、緊急連絡先、顔写真を確認できる社員一覧です。名前や部署名での高速検索が可能です。

🛠️ 第12章: ユーティリティー・便利機能
全員対象

左側サイドバーの「ユーティリティー」メニューを展開することで、本マニュアルの閲覧や各種専用ツールへ素早くアクセスできます。

⚙️ 第13章: 管理者パネル・システム設定
要管理者権限

システム全体の管理、ユーザーの登録・権限付与、各メニューの表示制御、推奨サーバーコードの確認を行う管理機能です。

管理者が設定できる項目

  • 社員アカウント管理: 新規登録、パスワード変更、アカウントの有効/無効化、管理者権限の付与。
  • 個別メニュー表示切り替え: 社員ごとに「点検予定管理」「共有ファイル」「安否確認発動」の各メニューの表示/非表示を個別にON/OFF可能。
  • 推奨バックエンドコード (RecommendServerCode): NAS本番サーバー用の最新のExpress/MS SQL Serverルーターコードの確認・エクスポート。
