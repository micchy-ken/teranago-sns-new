寺岡オートドアSNS / 寺子屋SNS 総合操作マニュアル

社内ナレッジの蓄積・タイムライン・日報・チャット（@特殊コマンド群）・点検予定管理・文書キャビネット・安否確認の全機能を網羅した公式操作ガイドです。

バージョン: v2026.11.06 #7 (完全版) 最終改定日: 2026年11月6日 タイムゾーン: 日本標準時 (JST / UTC+09:00) 厳格準拠 対象: 全社員・管理者・現場技術員
🌟 第1章: はじめに・システム概要・推奨環境・PWAインストール
全員対象

本システムは、寺岡オートドアグループの技術・現場ナレッジの共有、スケジュール・点検予定の可視化、災害時の迅速な安否確認を実現する社内統合プラットフォームです。GitHub Pages上のフロントエンドと、社内Synology NAS上のセキュアなバックエンド（MS SQL Server / AES-256暗号化）がリアルタイムに連携稼働しています。

推奨利用環境

端末種別 推奨ブラウザ 特徴・利用上のポイント
パソコン (Windows / Mac) Google Chrome, Microsoft Edge (最新版) 大画面での点検Excel取り込み、カレンダーマトリクス操作、文書管理、管理者パネルに最適。
スマートフォン (iOS / iPhone) Safari (最新版) PWAインストール（ホーム画面に追加）により、全画面起動とWebプッシュ通知受信に対応。
スマートフォン (Android) Google Chrome (最新版) PWAインストール対応。安否確認や現場からの写真付き日報・チャット投稿がスムーズです。

PWA（プログレッシブウェブアプリ）のインストール手順

  1. iPhone (Safari) の場合: 画面下部の中央にある「共有」アイコン（四角から矢印が上に出ているアイコン）をタップし、メニュー一覧から「ホーム画面に追加」を選択します。
  2. Android (Chrome) の場合: 画面右上のメニュー「︙」をタップし、「アプリをインストール」または「ホーム画面に追加」をタップします。
  3. パソコン (Chrome / Edge) の場合: アドレスバーの右端に表示される「インストール」アイコンをクリックすると、独立したデスクトップアプリとして起動できます。
🔔
Web Push通知の許可: 初回ログイン時またはヘッダー右側のベルアイコンから「通知を許可」してください。緊急安否確認やチャットメンション、重要掲示板の通知をリアルタイムに受け取ることができます。
🏠 第2章: タイムライン (社内ナレッジSNS)
全員対象

日常の業務の気づき、現場トラブルのシューティング、新製品や施工ノウハウを気軽に発信・共有できるタイムラインです。

主な機能と操作詳細

機能 説明 操作方法・Tips
新規投稿 テキスト本文、最大10枚の現場写真添付、自動リサイズ（EXIF位置情報の自動削除対応）。 画面上部の投稿フォームに入力し「投稿する」をクリック。URLを貼り付けると自動でリッチカード（サムネイル・タイトル付き）に変換されます。
アンケート作成 2〜6個の選択肢を設定し、社員から意見や投票を集計（1人1票）。 投稿フォームの「📊 アンケート」アイコンをクリックして質問と選択肢を入力。
スタンプ・いいね ワンクリックで感謝や了解、お疲れ様の意を伝えるオリジナルスタンプ。 投稿下部のスマイルアイコンからスタンプを選択。リアクションした社員一覧も確認可能。
コメント・スレッド返信 投稿に対する詳細な議論や質問、現場からの追加写真共有。 「💬 返信する」をクリックして入力。スレッド形式で会話が整理されます。
ナレッジ検索・絞り込み 過去の投稿をキーワード、投稿者、添付ファイル有無で高速全文検索。 タイムライン上部の検索バーにキーワードを入力してEnter。
📋 第3章: 業務日報・現場作業報告
全員対象

現場施工・保守点検の作業記録、進捗、出勤状況を作成し、上長やチーム内で共有・承認を受ける機能です。

日報の作成・承認ワークフロー

  1. 「新規日報作成」をクリック: 日付（初期値は本日・JST）、作業現場名、案件番号を選択または入力します。
  2. 作業内容と所見の入力: 「自動ドア修繕」「定期点検」「新規据付」などの作業区分を選び、作業時間・交通費・現場写真を登録します。
  3. 下書き保存・提出: 作業途中なら「下書き保存」で中断可能。完了時は「提出する」を押すと、上長へ通知されます。
  4. 上長承認とコメント: 管理職（主任・課長・部長）は提出一覧から内容を確認し、「承認印」または「差し戻し（修正指示コメント付き）」を行います。
💡
過去日報のワンクリック引用: 同じ現場の定期点検や前日の続き作業を行う場合、「前回の作業内容を引用」ボタンを押すことで、現場名や基本項目が自動セットされます。
📢 第4章: 社内掲示板・公式回覧板
全員対象（投稿権限は部署・役職に応じる）

全社通達、総務・経理からの重要連絡、安全衛生マニュアルの改定などをカテゴリ別に周知・回覧する公式掲示板です。

掲示板の独自機能

  • 重要ピン留め機能: 緊急通達や必読連絡は一覧の最上部にハイライト固定されます。
  • 未読・既読トラッキング（全員の閲覧状況）: 投稿者および管理者は、「誰が閲覧済みで、誰が未読か」の社員名一覧をいつでも確認できます。
  • PDF・文書のインライン表示: 添付された回覧PDFや図面ファイルをダウンロードせず、ブラウザ内で即座に全画面プレビューできます。
  • カテゴリ分類: 「全社通達」「総務・人事」「安全衛生」「技術・施工」「イベント」などのタグで素早くフィルタリングできます。
💬 第5章: グループチャット・DM＆特殊機能（@コマンド全8種）
全員対象

1対1のダイレクトメッセージ（DM）および部署・プロジェクト別のグループトークルームで、リアルタイムなメッセージングと業務カードの活用が可能です。

チャットの基本操作と便利機能

  • メッセージ送信・改行: Enter で即時送信、Shift + Enter で改行します（日本語変換中のEnter誤送信防止機能付き）。
  • 写真アルバム一括送信: 最大10枚の現場写真を一度に送信可能。超高速軽量サムネイルで表示され、クリックするとLightbox拡大表示されます。
  • 既読メンバー一覧: 送信メッセージ横の「既読」をクリックすると、そのメッセージを読んだメンバーの顔写真と既読時刻一覧を確認できます。
  • ボスモード (業務偽装モード): ヘッダーまたは入力欄横のメガネアイコンをクリックすると、画面全体が地味なグレーの業務管理表スタイルに瞬時に切り替わり、周囲からの視線をガードします。
  • URL貼り付け時のリッチカード化: Webサイトや社内リンクを貼り付けると、自動的にタイトル・概要・サムネイル付きのリンクカードが生成されます。

📅 第6章: 共有カレンダー・予定管理・日程調整
全員対象

全社員の予定、現場施工、定期点検、社内行事を日・週・月単位で可視化します。すべての日時計算は日本標準時 (JST / UTC+09:00) に厳格準拠しています。

主な機能

  • 終日予定・時間指定予定: 現場直行・直帰、出張、有休、会議などの区分を色分け登録。
  • 空き枠自動抽出・日程調整機能: 複数人のカレンダーから共通の「空き時間枠」を自動抽出し、会議や現場打ち合わせの候補日時を瞬時にリストアップできます。
  • 外部カレンダー連携 (iCal URL発行): カレンダー右上の「iCal連携」をクリックして専用URLを取得し、Googleカレンダー、iPhone (iOSカレンダー)、Microsoft Outlookに登録することで、社外のスマートフォン標準カレンダーへリアルタイム自動同期されます。
🗓️ 第7章: 点検予定一括登録・管理
要権限（管理者または個別許可）
🔑
利用権限について: この機能は「管理者」または管理者パネルで「点検予定管理メニューの表示」が許可されたユーザーのみ利用可能です。

毎月の定期点検Excel（26列実フォーマット）を取り込み、日付配置・担当者割り当て・現場カレンダーマトリクスExcel出力を一気通貫で行う専用業務機能です。

業務フローと機能一覧

機能名 説明・操作ポイント
実フォーマットExcel取込 現場から配布されるExcelファイル（.xlsx）をドラッグ＆ドロップ。C1セルの年月や26列に及ぶ現場データを正確に自動読み込みします。
現場マスター自動補正 過去の点検実績データから「現場ごとの開始時間・貼紙・作業届・WEB入力区分・備考」を照合し、自動引き継ぎ補正します。
他月・前月データコピー 前月の下書きや配置済みデータをマスター情報付きでワンクリック一括コピーし、今月分の初期配置を迅速化します。
点検予定表Excel出力 現場カレンダー形式（縦軸＝日付・曜日、横軸＝案件、土日色分け・特記事項オレンジ強調）で完全互換のExcelシートを出力します。
カレンダー確定反映 仮配置した点検予定に担当技術員を割り当て、共有カレンダーへ一括登録して全員に共有します。
📁 第8章: 社内文書管理・キャビネット
全員対象（一部フォルダは権限制御）

社内規程、業務マニュアル、申請書テンプレート、施工図面などを階層フォルダで安全に一元管理します。

操作ルールとセキュリティ

  • 文書詳細と改定履歴: 文書名をクリックすると詳細モーダルが開き、過去の全改定履歴（バージョン1.0, 1.1...）、改定理由、更新者を確認できます。
  • 添付ファイルの即時プレビュー: ファイル名をクリックするだけで、ブラウザ内でPDF・画像・テキストを高速インライン表示します。
  • フォルダ公開範囲の制御: 「全社員公開」のほか、「特定部署のみ」「特定メンバーのみ」の閲覧制限フォルダを作成できます（作成者・管理者のみ設定可能）。
  • ダウンロード・閲覧監査ログ: 誰がいつどのファイルをダウンロード・閲覧したかが自動記録され、情報漏洩や不正持ち出しを抑止します。
🗄️ 第9章: NAS共有ファイル (社内ストレージ連携)
要権限（個別許可）

社内NAS（Synology）上の特定共有フォルダと直接連携し、外出先や自宅からでも安全に社内大容量ファイルを閲覧・ダウンロードできます。また、外部取引先への一時受渡ファイル（パスワード保護・有効期限付き）の作成も可能です。

🦺 第10章: 安否確認・緊急BCP連絡
回答:全員 / 発動:要権限

地震・風水害・大規模火災などの緊急事態発生時に、全社員へ一斉に安否確認を発動し、回答状況をリアルタイムで集計・可視化するBCP（事業継続計画）機能です。

全社員の回答手順

  1. 発動通知の受信: 安否確認が発動されると、アプリ画面上部に「緊急安否確認バナー」が表示され、スマートフォンへのWebプッシュ通知および登録メールアドレスへ一斉送信されます。
  2. 「安否を回答する」をクリック: バナーまたは通知から回答モーダルを開きます。
  3. 状況の選択と送信:
    • 本人状況: 「無事」「軽傷」「重傷」
    • 出社可否: 「即時出社可」「本日不可（明日以降可）」「当面出社不可」
    • 家族状況・自宅状況: 「全員無事」「被災あり」
    • 現在地・コメント: 現在いる場所や救援依頼などの詳細を入力して送信します。
⚠️
安否確認の発動権限: 誤発動を防ぐため、安否確認の一斉発動は「システム管理者」または「安否確認発動権限」を持つ担当者のみが実行できます。発動後は拠点別・部署別の回答率グラフがリアルタイム更新されます。

⚙️ 第13章: 管理者パネル・システム設定・運用
要管理者権限

システム全体の管理、ユーザーの登録・権限付与、各メニューの表示制御、推奨サーバーコードの確認を行う管理機能です。

管理者が設定できる項目

  • 社員アカウント管理: 新規社員登録、パスワード変更、アカウントの有効/無効化、管理者権限の付与。
  • 個別メニュー権限の切り替え: 社員ごとに「点検予定管理」「NAS共有ファイル」「安否確認発動」の各メニューの表示/非表示を個別にチェックボックスでON/OFF制御可能。
  • 代理ログイン機能 (Impersonation): 管理者は社員一覧から「代理ログイン」を実行し、該当社員の視点での画面表示や権限状態を安全に検証できます。画面上部の「管理者に戻る」ボタンを押すことで、ワンクリックで元のアカウントに復帰します。
  • 推奨バックエンドコード (RecommendServerCode): Synology NAS本番サーバー用の最新のExpress/MS SQL Serverルーターコード（routes/*.js）をUI上で確認・エクスポートできます。

❓ 第15章: よくある質問・FAQ・トラブルシューティング
解決ガイド

よくある質問

  • Q: Webプッシュ通知が届かない場合は？
    A: ブラウザのアドレスバー左側にある鍵マーク（サイトの設定）をクリックし、「通知」が「許可」になっているかご確認ください。スマートフォンの場合は、端末自体の「設定 ＞ 通知 ＞ ブラウザ」で通知が許可されているかもご確認ください。
  • Q: チャットで@コマンドを送信したのにカードにならない場合は？
    A: コマンドの先頭に余計な文字が入っていないか、半角の @secret や @shout になっているかご確認ください。入力欄左の「＠」ボタンから挿入すると入力ミスを防げます。
  • Q: 外部カレンダー（Google/Outlook）に予定が反映されない場合は？
    A: iCal購読の更新頻度はGoogleやOutlook側の同期間隔（通常数時間〜半日）に依存します。即座に確認したい場合は社内SNSアプリ上のカレンダー画面をご確認ください。
  • Q: パスワードを忘れた場合の対処方法は？
    A: 社内のシステム管理者に連絡してください。管理者パネルの社員一覧からパスワードの再発行・初期化が可能です。
